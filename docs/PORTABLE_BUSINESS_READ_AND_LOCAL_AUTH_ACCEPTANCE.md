# Shared business reads and local authentication client

The development libraries now use the same owned read services for Samples, Project snapshots and Template directories on Node/SQLite and Cloudflare/D1. The Node client has an explicit local-session gate, memory-only CSRF, request ownership and no write replay after an uncertain outcome. The Cloudflare build keeps its existing fetch behavior.

Actual focused results: Samples Node8/Worker7, Project Node6/Worker4, Template Node6/Worker4, and authentication client15/mounted5 all passed, 55 cases across separate finite runs. Worker cases use a genuine bundled entry and native D1/R2; Node cases use the installed current23 catalog, exact native integer cells and mature SQL guards. Server, Worker, client and explicit new Worker-test strict scopes passed. The independent Node client build and bundle qualification passed. Authentication client fixtures are controlled transports, so these do not prove a complete real browser/local-session/business composition.

Processing matching-run filters originally returned500 because the count query received three extra bindings. This was reproduced against original Worker source, extracted Worker source and Node/SQLite. The shared count WHERE now includes the same matching-run filter as its bindings and row query. Both runtimes passed all13 family/run-status/Processing-status combinations, with row results, facet counts and pagination checked together. An unrelated native fixture attempted an application PRAGMA and was correctly denied; its foreign-key assertion now uses the privileged fixture connection, preserving the application boundary.

The first Project run correctly refused a pristine fixture without WAL. The fixture now explicitly enables WAL before the unchanged installer. The 201-reference boundary then exceeded the unchanged five-second default: measured fixture seeding took8.4s while actual snapshot/reference reading took15.5ms. Preparing the same four seed statements once and committing the full guarded fixture before admission resolved the cost. All201 references, tombstone, order and two resolver-batch assertions remain. The independent native writer contention test also passed. Test bytes subsequently moved from .qualification.ts to .test.ts so existing source CI executes the new native cases.
