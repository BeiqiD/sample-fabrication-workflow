   automatic graph-publication slot, using its cached original first close ACK.
3. A new PID starts on the same unchanged configuration/database. Ordinary login
   and same request-ID replay recover the original queued job. The first new
   automatic slot publishes its accepted graph; the following two slots export
   that graph and read the original payload back through the native provider.
