# Native V5 target constructor: two-case source

Parent implementation: `2e5b56240d981e7eda45e24073b84f26c8858816`; Root's complete
Worker type check passed for that source. This overlay adds only the opt-in QA
file, dedicated Vitest configuration and strict QA type configuration. Both new
native cases are SOURCE-only/UNRUN here; Root owns compilation and execution.
Their explicit60/120-second case bounds leave all existing/default limits intact.

Inputs are the original genuine Node producer
`9c7c916d9647ffac8efc163c2b7213b40617cb41` zero-File and one-File V5 ZIPs, with
their original PASS/owned-close receipts. The nonempty input contains the genuine
ordinary HTTP LOCAL upload, not hand-inserted File rows. Root supplies absolute
original paths and complete SHA-256 pins through these names:

```text
WORKER_V5_ZERO_ARCHIVE
WORKER_V5_ZERO_SHA256
WORKER_V5_ZERO_PRODUCER_RECEIPT
WORKER_V5_NONEMPTY_ARCHIVE
WORKER_V5_NONEMPTY_SHA256
WORKER_V5_NONEMPTY_PRODUCER_RECEIPT
WORKER_V5_NATIVE_FIXTURE_PARENT
```

The QA checks the original producer head, one-case PASS and actual owned closure,
the immutable original ZIP hash, and original file paths. Neither original archive
nor receipt is copied or changed. New D1 constructor results belong to the new
QA/implementation head only; retained Node producer results keep their old scope.

Each case bundles the exact candidate in a native Miniflare isolate, provisions
two real native D1 bindings and one real native R2 binding, and installs only
the reviewed24 forward migrations into source DB using their hashes and Wrangler
statement splitting. RECOVERY_DB starts genuinely empty. There is no host/isolate
D1 adapter and no handwritten business/profile/runtime metadata. R2 registration
uses the original bootstrap service; original shadow enable/profile-enable
commands create its recorded writable state. The isolated fixture actor supplies
that internal command context; these two constructor cases do not certify Access
authentication or deployed operator admission.

The isolate independently admits the original V5 ZIP before constructing the
target. Its independent oracle compares every original nonlocal typed row/cell/
rowid directly, allowing only account `enabled=0`; it does not call the target
projection helper to manufacture expected rows. It checks every local authority
table empty and the six singleton controls exactly inert, whole V28 schema and
reviewed ledger, foreign keys and quick-check. Every supplied typed storage class
is compared exactly; absent NUL/BLOB/wide-integer examples remain unexercised.
The nonempty case retains the complete original LOCAL descriptor and requires an
explicit exact registered-R2 revision1 plan, including missing-mapping rejection.
The real R2 binding is forwarded through a call observer, proving zero PUT/DELETE;
the physical bucket stays empty. Source DB and original archive/receipt hashes
must remain unchanged, and repeated constructor calls retain the first Promise.

Each original asynchronous operation is joined before the original Miniflare
dispose. Partial native databases remain in the new private fixture directory.
One private response artifact per case retains the original native error when a
case fails; assertions print only fixed phase/reason facts. Native closure failures
preserve the original operation failure and prevent a PASS.

Run the dedicated config only after materializing this overlay on its parent and
qualifying `tsconfig.worker-v5-native-qualification.json`. These cases do not copy
or publish payloads, prove V5 source capture on Worker, close online Jobs/cadence,
make a target recovery-ready, serve business routes, activate resources, deploy or
merge production main. LOCAL-origin evidence/codec and verified byte publication
are the next separate source slice.
